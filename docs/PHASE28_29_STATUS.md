## 影响研究方向的结果

Phase 28 保留了公开源表中的原始行号、重复时间戳和单位歧义。电极电位相对于 NHE 的变化不能直接当作全电解槽电压，连续时间采样也不能当作独立电极重复实验。成本敏感性计算使用显式假设的电价、失活率和更换成本；它的作用是找出需要测量的量，当前没有证明工业降本。

Phase 29 的 JACS 示范反应使用 4-苯基吡啶与苯甲醛，C4 已被占据；Nature Communications 示范反应使用 2-苯基吡啶与对甲氧基苯乙酮，C2 已被占据。产物分别是不同的仲醇和叔醇。这一比较揭示了后续对照实验必须固定底物、羰基试剂和原子编号，不能把不同路线的位点选择性拼成切换证据。来源定位与手工重建的映射见 [Phase 29 文献数据](../projects/phase29/data/literature/)。

[独立 xTB 诊断](../projects/phase29/results/quantum_preflight/README.md)对三个假设的 N-质子化分子做了两种方法、两个电荷/自旋状态的固定核坐标计算。GFN1/GFN2 的相对能量差异为约 0.736–1.021 eV；12 次运行均报告 SCC 收敛与正常结束，也均保留 Windows 数值警告。ALPB 对各状态分别平衡，因此这些数值不是严格的非平衡溶剂垂直电子亲和能、实验电位或位点选择性。它们支持保留方法适用性疑问，不能用于补齐表面反应机理。

## 后续推进所需证据

| 目标 | 需要取得或执行的证据 | 在取得前的处理 |
|---|---|---|
| 电极失活路径 | 对应同一电极的电压、表面物种、溶出物与对照测量；可追溯批次 | 只做候选机理和可辨识性设计 |
| 工业寿命与成本 | 全槽电压、FE、纯度、启停、维护、更换及分离能耗的实际记录 | 使用带来源或显式假设的情景区间 |
| C2/C4 可切换性 | 同一未封锁底物、同一羰基试剂下，两种可重复条件及完整物料衡算 | 不给真实反应输出已校准预测 |
| 定量反应机理 | 有依据的催化位点/界面、溶剂化和电位处理，收敛与竞争路径验证 | 分子预检与假设模型单独标记 |
| 创新性成立 | 与近期竞争文献逐项对比，并用新证据排除已有解释 | 创新表述保留为待检验问题 |
