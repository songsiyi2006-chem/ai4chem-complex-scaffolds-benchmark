## 四层证据不能互相替代

| 层级 | 能支持什么 | 不能直接支持什么 |
|---|---|---|
| 软件检查 | 指定输入下的实现、边界处理与回归行为 | 真实化学准确性 |
| 已执行计算 | 指定方法、体系与参数下生成了输出 | 充分采样、收敛或方法适用性 |
| 科学验收 | 对应任务的收敛、对照、误差和连接性要求 | 未覆盖体系的泛化、真实实验效果 |
| 实验 / 硬件验证 | 有来源的实际测量或设备执行记录 | 仓库中的模拟与协议编译不能替代这一层 |

阅读数值时同时检查：输入、方法、运行范围、原始日志、验收门槛及局限。文件存在或进程退出码为零均不等于科学验收完成。

## 历史文档的使用

Phase31 的七角色是本地确定性调度与未来 LLM 接口，不是已完成的 1 亿 Token 蜂群计算。原始 ωB97X-D 方法兼容性、QM/MM 力耦合、采样、IRC 等生产证据未通过；公开 6SIS 与低成本 MMFF 构象不得冒充这些结果。见[完整边界](../projects/phase31/reports/phase31_scientific_full.md)。

[历史首页](history/README_HISTORY.md)保留原文，便于追溯。其早期性能数字、宣传性徽章、机器绝对路径和“运行中”措辞均需结合后续更正解读。归档本身不代表认可或重新验证这些结论。

1–27 阶段迁移代码、报告和结果目录并增加兼容运行入口；这些阶段的科学代码与非 Markdown 数据保持原字节，迁移不代表生产重算。28–29 阶段的公开数据复算和本机计算是独立新增工作，不能回填为旧阶段验收证据。
