## 一、认识论前沿

万神殿此前所有阶段,都是在人类写下的方程里做计算。第十二阶段把人类从"理论形成"这一环中彻底移出。机器得到的只是来自非平衡化学体系的含噪高维时间序列,并被命令交还:

1. 控制演化的**符号非线性微分方程**;
2. 隐藏的**守恒第一积分**——不变流形的哈密顿核;
3. 执行热力学第二定律的 **Lyapunov 熵耗散泛函**;
4. 区分近平衡热力学与驱动非平衡的 **Onsager 倒易结构**。

这不是曲线拟合。回归器做的是插值;理论家必须对**符号本体论**做出承诺——对自然界中哪些项真实存在给出离散的断言,并以人类可读、可证伪、可编译、可迁移的语言书写。

## 二、估计器:让稀疏回归在 5% 噪声下 statistically 诚实

教科书式 SINDy 在刚性振子的 5% 噪声下必死:数值微分把传感器噪声放大三个数量级,一切结论崩塌。第十二阶段的估计器针对四条独立的失败通道逐一工程化,每一条都在本体系上被诊断并定量:

| 失败通道 | 诊断 | 实施的 remedy |
|---|---|---|
| 微分放大 | 5% 噪声下 σ(ẋ)/信号 > 100% | **弱形式**(对紧支集测试函数 φ 分部积分):噪声仅以窗口平均线性泛函进入 |
| 误差-in-变量衰减 | 库噪声使系数系统性缩小约 16% | **分样窗口**(靶侧取偶节点、库侧取同一区间内点——两组独立噪声实现)+ **蒙特卡洛噪声校准 Gram**:从 Gram 中减去 E[NᵀN],衰减压缩到 **1.5% 以内** |
| 窗口支撑错位 | 靶窗与库窗之间相差一个采样点的奇偶偏移 | 同跨度双网格求积(靶在偶节点、库在同区间内部奇节点,Simpson/梯形权) |
| 跳跃不连续 | 脉冲实验使跨越跳变的窗口违反弱恒等式(多出 Δx·φ(t_kick) 项) | 踢实验返回**前后独立片段**;任何窗口不跨越不连续 |

候选函数库 Θ(x) 共 **44 项**:幂次不超过 4 的全部多项式、Michaelis–Menten 型有理饱和项 u/(K+u)(K ∈ {0.02, 0.2, 2}),以及反应–扩散阶段的谱 Laplacian 列(高斯预平滑 + Wiener 去卷积)。

## 三、认识论闭环:观测 → 干预 → 仲裁 → 发现

选择(模型选择)是自主科学要么真实发生、要么被伪造的地方。第十二阶段实现了完整闭环,每一阶段都由证据状态机械触发:

1. **观测。** 5% 噪声下的被动遥测(极限环轨道 + 盆地暂态);STRidge 路径、前向/后向消元、随机重启迭代硬阈值生成候选支撑;噪声校准修正残差给出逐复杂度 Pareto 前沿。
2. **干预。** 在极限环上,俄勒冈冈自身满足快零倾线约束 u(1−u) ≈ uv − qv,使真实项组 {v, uv, u, u²} 与替代项组(如 {uw,…})近乎共线——被动数据*原则上无法*裁决。理论家据此设计**因子化脉冲实验**:单变量踢、盆地裁剪(u ±0.35、v +1.5/−0.35、w ±0.45),向窗口注入流形外信息。
3. **仲裁。** 在运算精度下仍不可区分的对手定律,由**更高精度的复测实验**裁决:两组独立的 1% 复测;系数在 A 组拟合、在 B 组独立复测上评分——模型在 A 上吸收的库噪声不会迁移到 B,残差比较再经 B 自身噪声 Gram 去衰减(SSE\* = SSE_B − cᵀG_N B c)。复杂度平局由奥卡姆剃刀(校准带内最小支撑)裁决。
4. **发现。** 获胜支撑的系数在*全部* 5% 运算遥测上以校准 Gram 重拟,定律以 SymPy、LaTeX 与编译 C++ 三种形式输出。

**结果——机器仅凭 5% 噪声写下的定律:**

- du/dt = 10.06·u − 10.01·u·v − 9.99·u² + 0.0253·v(真值:10、−10、−10、0.025)——系数最大误差 **1.35%**
- dv/dt = −0.2441·v − 99.94·u·v + 109.76·w(真值:−0.25、−100、110)——最大误差 **2.27%**
- dw/dt = u − w(支撑精确)——最大误差 **0.07%**

**结构保真:** 对发现的方程组积分,极限环周期误差 **0.04%**(10.1160 对 10.1203 τ),Lyapunov 谱误差 < 1%(λ = [−0.002, −0.925, −69.69] 对 [−0.003, −0.931, −69.93] τ⁻¹——中性相方向 + 耗散收缩)。

## 四、哈密顿核与 Lyapunov 熵耗散(模块 12C)

辅助连续神经微分算子(3→64→64→1 MLP,softplus,autograd 梯度)直接*在已发现的定律上*训练——理论家自举:

- **哈密顿核 H(x):** 训练目标 ∇H·f ≈ 0(吸引子带上),辅以轨迹端点一致性对与反塌缩铰链。学得的 H 以 **1.5% 角度残差**满足无穷小不变性——这正是第一积分限制在耗散极限环上的正确表述(环上 H 沿流守恒;横向变化仍属规范自由度)。
- **Lyapunov 泛函 V(x) ≥ 0:** softplus 头网络,流形外 d V/dt ≤ 0、流形上 V → 0 且 Ḋ → 0。审计:V 处处非负;流形外平均 Ḋ < 0;环上近平衡稳态平衡 ⟨Ḋ⟩ ≈ 0 而 Ḋ-rms > 0——这正是**非平衡稳态**的签名:熵输出与内部耗散达到平衡。

## 五、Onsager 门槛

在可激发域(f = 2.8,稳定定态)对已发现动力学做重拟,并接受线性不可逆热力学的审问:在一切 SPD 度规补全 G 上,把 Onsager 矩阵 L = −J G⁻¹ 做到最大对称,同时报告两个 regime 中 (L+Lᵀ)/2 的谱。两个 regime 中 L 的对称性都可实现;真正区分它们的是**耗散约束**——稳定定态处的对称补全保持 PSD 一致,而受迫振荡域中对称补全强烈不定。倒易得以幸存,细致平衡被打破——这恰恰是靠进料维持的化学振子远离平衡的热力学签名。

## 六、为何这是一次边界突破

化学中的机器学习一直是插值器:它复现我们已会书写的东西。第十二阶段的结果是范畴上的不同:

- 输出是**符号的**——它对哪些项存在做出承诺;
- 它是**可认证的**——复测实验仲裁、噪声校准协方差、以及任何回归器都无法提供的结构保真检验(周期 0.04%)在支撑它;
- 它**在世界中行动**——闭环自主决定做哪些实验(干预)、仪器何时不足(仲裁)、以及自然属于哪个复杂度类(奥卡姆)。

同一套机器把自产的定律编译为 C++(`phase12_kernels.hpp`)——它发现的理论原生运行在下一阶段的模拟器中。至此,远征闭合:中心科学(第 1–8 阶段)获取了世界的结构;物理世界模型(第 9–11 阶段)赋予它双手与双眼;第十二阶段赋予了它在物理学最古老语言——微分方程——中的发声权,以及赢得这一发声权的认识论纪律。**科学 AGI 不是知晓一切模型;它是一个能被交予未知、并交还定律的过程。**
