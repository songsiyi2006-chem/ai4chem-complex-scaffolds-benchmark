# Phase 28 大型研究任务提示词

## 工业氯碱有机电极：面向波动电力的失活机制、寿命预测与能耗协同设计

**英文工作题目：** Identifiable Degradation Mechanisms and Lifetime–Energy Co-design of Organo-electrodes for Flexible Chlor-Alkali Manufacturing

**版本：** 2026-09-20。本文是可复制使用的任务提示词，不是研究结果、实验方案批准件或工业可行性结论。下列数量与指标均为拟议研究设计，执行时须在看见测试结果前冻结。

## 直接使用的提示词

你是一名计算电化学、有机催化、电极界面、化工过程和不确定性量化方向的研究负责人。请基于 `ai4chem-complex-scaffolds-benchmark` 开展 Phase 28，形成一个具有明确科学问题、产业约束、可重复计算和可证伪结论的大型研究项目。

核心问题是：**酰胺类有机电极在工业相关氯碱条件与波动供电下，活性位点如何形成、失活和恢复？能否通过分子结构、锚定方式及受约束的电流调度，提高全寿命合格产品产出，而不是仅提高某条极化曲线的初始性能？**

目标面向高水平原创研究，但不得承诺发表档次。创新性必须通过现有工作对照和新证据证明。若缺少实验、算力或关键输入，应交付相应层级的成果，并明确尚未达到的验收项。

### 1. 文献起点与证据边界

优先核查以下成果，正确注明联合作者和合作单位，不将合作论文归为唐海涛课题组独立完成。

1. **Yang 等，Nature，2023**：*CO2-mediated organocatalytic chlorine evolution under industrial conditions*。DOI：[10.1038/s41586-023-05886-z](https://doi.org/10.1038/s41586-023-05886-z)。[PubMed 原论文摘要记录](https://pubmed.ncbi.nlm.nih.gov/37198309/)。可作为酰胺有机催化剂、CO₂ 参与及析氯界面的研究起点；不能据此假定所有衍生物均有效。
2. **Yang、Lai、Tang 等，Nature Synthesis，2026**：*High-efficiency organo-electrocatalysts enable both anodic and cathodic reactions*。DOI：[10.1038/s44160-026-01039-y](https://www.nature.com/articles/s44160-026-01039-y)。论文报告酰胺类有机电催化体系及氯相关反应，是必须正面对照的近邻工作。
3. **Euro Chlor 行业资料**：[行业年度报告入口](https://eurochlor.org/library/industry-review/)、[2025–2026 竞争力章节](https://www.chlorineindustryreview.com/competitive-supplier/)。用于获取电力成本、产能利用与工艺背景，不作为本项目客户订单或当地工厂数据。
4. **Euro Chlor 历史电网调节讨论**：[2022–2023 年度报告](https://www.eurochlor.org/wp-content/uploads/2023/10/Chlor-Alkali-Industry-Review_CORRECTED-2023-10-06.pdf)。其意义在于提示电力调节受到生产和储存约束；历史比例不可作为当前行业数值。

本提示词编制时核对了公开出版信息、摘要/出版商页面及行业页面，**未逐页审计两篇论文的全部 SI、原始谱图或寿命测试数据**。执行任务时建立 `literature_claims.csv`，逐项记录 DOI、图表/SI 页码、访问层级与缺失项。不能读取的位点结构、制备细节、iR 校正方法和耐久数据写为 `unverified`，不得自动补齐。

全项目统一使用以下证据标签：`LITERATURE_FACT`、`HYPOTHESIS`、`EXECUTED_CALCULATION`、`MODEL_INFERENCE`、`EXPERIMENT_REQUIRED`。代码测试另列为 `SOFTWARE_CHECK`。工业相关工况测试不等于工业装置长期运行。

### 2. 与既有阶段的关系

- 读取现有 `projects/phase01` 至 `phase27` 的入口和验收状态，复用有明确来源的工具，不重复宣称其科学结论已全部通过。
- Phase 10 的流动/控制模型只能作为软件参考；Phase 24 的合成响应不能用于训练真实电极寿命模型。
- Phase 26 的铜界面方案不是本任务的已校准界面。不得把其干表面或未验收能量移作析氯自由能。
- 本项目新增的主贡献必须是**有可识别物理含义的失活状态、可独立验证的动态预测和同产出约束下的全寿命收益**，不能仅新增一个控制面板或套用强化学习。

### 3. 必须竞争的机制假设

至少建立四个有不同可观测后果的机制模型：

| 假设 | 核心解释 | 区分证据，而非单一佐证 |
|---|---|---|
| H1：固定有机位点介导 | 锚定有机分子的可逆状态转化控制有效活性 | 有机层覆盖度、标记响应、可逆光谱变化与反应瞬态共同约束 |
| H2：溶出/可溶物介导 | 脱附组分或其转化产物承担主要催化作用 | 电解液转移、溶出定量、表面变化和反应持续性联合判断 |
| H3：碳载体/缺陷主导 | 有机层主要改变润湿、缺陷或局部传质 | 匹配润湿与电阻的惰性层、空白载体和结构不同但物性相近的对照 |
| H4：传质/测量表观增益 | 气泡、欧姆降、局部组成或有效面积造成表观提升 | 独立传质表征、面积口径、未校正/校正数据和全槽能耗对照 |

将“动态波形可以减缓失活”作为待检验假设，不能预先写入寿命模型。若只改变平均负荷即可解释效果，应否定波形特异性；若只有频繁补充有机分子才能维持性能，须计入消耗和排放，不能称为自修复。

### 4. 工作包 A：新颖性审计与产业需求冻结

完成近邻论文、专利公开文本和设备背景检索。逐项比较：分子结构、固定方式、活性位点证据、动态工况、失活机制、寿命预测、放大尺度、系统能耗及成本边界。

至少给出三项可验证差异和两项可能导致本任务失去新颖性的先例。若已有工作完成相同机制与同等验证，缩小到尚未解决的识别问题，不能仅换催化剂名称继续包装。

将产业对象限定为氯碱电极供应商、膜电解系统集成商或生产企业中的一种主要用户。形成需求表：交付物、部署位置、允许停机、杂质容忍度、涂层更换方式、最低负荷、产品连续性、能耗统计边界及验收负责人。实际企业未提供的数据写 `not_obtained`；不得虚构合作、报价和装置试验。

预先冻结两条评估线：

- **机制线**：预测未参与拟合的瞬态与失活变化，区分至少两种竞争机制。
- **产业线**：同等累计合格产品、质量约束和生产节拍下，比较全槽耗电、辅助能耗、耗材、停机和总成本。

### 5. 工作包 B：数据与可重复基准

建立分层数据集，不将不同证据层混合成同一标签：

1. 出版物原始表格或明确数字化的数据；图像读数附误差与提取位置。
2. 经合作实验室确认的电极批次和运行数据。
3. 已实际执行的电子结构与动力学结果。
4. 用于软件测试的合成数据，单独目录存放，不能进入实际性能排行。

每次运行至少记录：电极批次、几何面积、载量/覆盖度及其测法、支持体、膜、液体组成、温度、流量、压力口径、参考电极与换算、iR 处理、电流/电压时间序列、产物流量/纯度、气液平衡处理、失活/中止原因和维护事件。

保留整个时间序列和异常数据；以电极批次、装置与时间分组划分训练/验证/盲测，禁止把同一寿命曲线相邻点随机分到两侧。低于定量限和未失效即结束的记录按删失数据处理。

建立可复现文献基线前，不启动上百个候选结构的批量计算。先选择少量具有可核查结构、电子计量和对照意义的代表电极；不得依据缺失的 SI 自行造出“文献结构”。

### 6. 工作包 C：界面状态与电子结构

建立“分子结构—锚定—界面组成—活性/失活状态”的候选图。分别考虑脱附、不可逆氧化/氯化、覆盖度变化和载体改变等可能路径，但仅对证据支持的路径投入高等级计算。

要求：

- 区分恒电荷模型与恒电位推断，说明参考电位、pH、离子环境与自由能约定。
- 电位敏感步骤不能只用真空气相反应能代替；界面模型须交代溶剂、离子、表面覆盖度、面积及采样范围。
- 对关键排序做泛函/溶剂/构象敏感性检查；若方法差异超过候选优势，结论为排序不稳健。
- 关键动力学路径需要适用的驻点、频率和连接性或自由能采样证据；单虚频或一张吸附构型图不等于完整机理。
- 禁止把 xTB 的预优化结果直接当作工业电位下的析氯势垒，也不能将 CO₂ 的可逆参与直接称作净碳捕集。

没有合适算力或界面引擎时，输出经检查的输入、方法选择和资源需求，状态为 `INPUTS_READY`；不得用代理常数填入实算结果列。

### 7. 工作包 D：可识别的动态模型

从最低必要复杂度建立状态空间模型。候选状态包括：活性有机位点比例、不可逆损失比例、溶出组分浓度、膜/欧姆电阻与传质状态。必须给出状态定义、单位、质量/电荷守恒和观测方程。

至少比較以下模型：

1. 恒定活性、无失活的基线模型。
2. 经验衰减/分段回归或生存分析基线。
3. 含竞争失活机制的物理模型。
4. 仅在残差结构支持时使用物理模型加统计修正。

执行结构可识别性或局部可识别性分析、参数相关性/剖面似然、后验预测检查及盲测。只有电压随时间变化时，不能同时声称独立识别所有化学失活参数；应指出必须补充的观测。

寿命定义要绑定预先冻结的性能失效标准。加速应力测试和正常工况若不共享失活机制，不得直接使用同一加速因子。禁止将数小时模拟外推成“数千小时已验证寿命”。

### 8. 工作包 E：动态操作与公平对照

使用受限的波形/调度参数，不预设深度强化学习。比较恒电流、简单规则、约束模型预测控制；复杂学习策略只有在前述基线之外提供稳定增益才保留。

必须设置：相同平均电流、相同累计电荷、相同累计合格产物、相同时间窗口等不同对照口径，并明确主口径为何适合产业问题。不能混用口径挑选最漂亮的结论。

将电价与功率可用性作为外生序列；把电流爬坡、产品供需、膜工况、温升、停机和储存能力纳入约束。控制器只能访问当时已可获得的信号；不能读取未来价格或测试集失活轨迹。

拟议盲测至少覆盖多个独立电极批次，以及正常运行、启停、负荷扰动和原料/环境变化。每类独立批次数应经功效分析确定；若仅有三个独立批次，也不能因此宣称可靠寿命分布已被精确估计。

### 9. 工作包 F：经济与环境边界

以“满足明确纯度要求的合格产品”为功能单位。氯碱联产品应说明分摊或系统扩展方法，并同时报告不分摊的装置总量；不能把每吨 NaOH 与每吨 Cl₂ 的能耗直接横向比较。

能耗核算包括积分全槽电功率及可获得的辅助用能；阳极过电位不能直接等同于全厂节电。成本至少包含电力、分子层制备/补充、载体与膜、维护停机、处置与产品不合格损失。

输出盈亏平衡电价/寿命/载量图和敏感性分析。电价、排放因子及企业价格附地区、年份和来源；情景参数不得写成真实报价。不得以只计算电费的模型宣称综合成本最优。

预注册一个产业“有价值改进”的门槛，例如在相同产出与质量约束下，评估全寿命单位产品成本下降是否达到 5%。**5% 是本项目拟议决策阈值，不是文献结论或必须实现的结果。** 同时报告不确定区间；若区间跨越零或收益由未经测量的寿命假设主导，判为证据不足。

### 10. 阶段门与停止规则

| 阶段门 | 通过条件 | 未通过时必须做什么 |
|---|---|---|
| G0 文献与身份 | 关键结构、测量口径和原始出处可核查 | 缺项登记，不虚构 SI，不展开无依据筛选 |
| G1 基线 | 正确实现守恒、单位、参考电位和已知对照 | 修复或明确方法不适用 |
| G2 机制识别 | 新观测可区分至少两种竞争模型 | 降低模型维数，提出最小区分实验 |
| G3 盲测 | 新批次/新时序预测经预注册指标评价 | 保留失败，不回流盲测后再报盲测性能 |
| G4 产业比较 | 同产出质量下成本/能耗比较完整，结论稳健 | 输出无优势区间和需要补测的参数 |
| G5 科学结论 | 机制、预测与产业分析互相一致 | 只声明真正通过的层级 |

不设置“必须找到最优电极”“必须超过商业 DSA”的结果要求。负结果若能明确失活机制或排除不经济区间，也是有效交付。原文 DSA 与本任务新对照的材料、面积和工况不同，必须披露。

### 11. 计算资源与执行方式

先盘点现有环境与数据，不重复安装。设置 `local / hpc / experiment` 三个配置层：本地负责文献、数据、低成本核验及低维模型；HPC 负责有必要的高等级界面计算；工业含氯测试由具备相应设施与操作条件的合作实验室实施。

每批计算前记录预计内存、线程、墙钟、停止条件和恢复方式。发现参数不可识别或结构证据不足时，优先改善证据设计，不用更大的模型掩盖问题。

## 提示词定位

这不是“再做一个析氯催化剂排行榜”。拟议贡献是把**有机电极真实活性来源、动态失活可识别性和全寿命产业收益**串成可验证的研究问题。是否构成足够新颖的工作，必须在执行时完成进一步查新和同行对照后决定。
